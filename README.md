# Griddle Royale — Shift Sim

Single-file browser game. Stack burgers, fry fries, pour drinks, serve tickets before customers walk out.

## Play

Open `index.html` or visit the GitHub Pages / your domain (griddleroyale.lol).

## Deploy

- Enable GitHub Pages on this repo (Settings → Pages → Deploy from main branch).
- Or point your custom domain to the Pages site / any static host.

Built as a pure HTML/CSS/JS shift simulator. No build step required.
