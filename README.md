# Griddle Royale — Shift Sim

**Play the game here → [https://griddleroyale.lol](https://griddleroyale.lol)**

Single-file browser kitchen shift simulator.

Stack burgers, fry fries, pour drinks, serve tickets before customers walk out.

## How to play
1. Click **Clock in**
2. Tickets print on the left — tap one to work it
3. Use Build / Fryer / Pour stations
4. Finished items land on the heat-lamp pass
5. Hit **Serve order** when the tray matches the ticket

No downloads. Just open the site and start your shift.
